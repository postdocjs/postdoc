# postdoc

## Usage

```sh postdoc [options] [command]```

## Options

- **version | v** Outputs the PostDoc version.
- **help | h** display help for command

## Subcommands

- **run** Starts development server with HMR and live preview.
- **init** Generates a default project structure and necessary files to start with.
- **test** Runs all test declared in the project.
- **build** Builds the project, copies assets into an output directory.
- **import** Creates new pages and minimal tests from a CLI project.
- **create** Generates assets depending on the used subcommand.
- **preview** Starts a simple static server over the output directory.
