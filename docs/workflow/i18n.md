# Internationalization (i18n) in PostDoc

PostDoc supports internationalization (i18n), allowing you to create documentation in multiple languages. In this document, we'll guide you through the process of setting up and using i18n in PostDoc.

## Setting Up i18n

First, you will need to specify the locales your project supports within your PostDoc configuration file (`postdoc.config.js`). Here is an example of how to define English and French as your site's locales:

```javascript
module.exports = {
  locales: {
    '/': {
      lang: 'en-US',
      title: 'My Project',
      description: 'Documentation for my project'
    },
    '/fr/': {
      lang: 'fr-FR',
      title: 'Mon Projet',
      description: 'Documentation pour mon projet'
    }
  }
}
```

In the example above, each locale is represented by a key-value pair. The key is the sub-path for the locale, and the value is an object containing locale-specific configurations, such as `lang`, `title`, and `description`.

## Creating Locale-Specific Content

Once you have defined your locales, you can create locale-specific content by adding a Markdown file in the correct subdirectory. For example, to add French content to the guide section of your site, you would add a Markdown file to the `guide/fr/` directory.

Each Markdown file represents a page in your documentation site. The locale of the page is determined by the directory it's placed in.

## Locale-Specific Layouts and Partials

Just like you can create locale-specific content, you can also create locale-specific layouts and partials. Simply place your locale-specific layout or partial file in the correct locale subdirectory in your layouts or partials directory.

## Switching Between Locales

To switch between locales, you can use the `$localePath` property available in your EJS templates. This property gives you the base path for the current locale, which you can use to construct URLs to other locales.

Here's an example of how to use `$localePath` to create links to the same page in different locales:

```ejs
<a href="<%= $localePath %>guide">Guide</a>
<a href="<%= $localePath === '/fr/' ? '/' : '/fr/' %>guide">Guide (Français)</a>
```

In the example above, the first link points to the guide page in the current locale. The second link points to the guide page in the other locale.

## Conclusion

This guide provides a basic overview of how i18n works in PostDoc. By specifying your locales in your PostDoc configuration, creating locale-specific content, layouts, and partials, and using the `$localePath` property, you can create a documentation site that supports multiple languages.
